# 大邑商：四土（Shangzhou）

**v1.0 · 首个完整可玩版**

一款以晚商中后期为背景的浏览器大战略 + 实时战术历史策略游戏。

设计目标不是把《全面战争》简单换成商周皮肤，而是让晚商时代本身产生玩法：人口、族人与奴隶、贝、粮食、草料、青铜装备、民夫、粮道、宗族人物、贡纳网络和战车共同决定一场战争打不打得起、打不打得赢。

## 主剧本

**西土渐强**

内部时间锚点约设在公元前1115年前后，用于驱动季节和人物年龄；晚商绝对年代本身存在学术不确定性，因此游戏界面使用“约前××年”，不把这一数字冒充精确史实。

商仍是最强政治中心，周保持与商的关系但正在西土成长；晋陕高地、东方、江汉、赣江流域和成都平原存在各自政治集团。所有势力运行在同一张持续战略地图上，不是章节关卡。

## 人口与经济

每个聚落至少区分：

- **族人**
- **奴隶**

征服可以产生俘口 / 奴隶；玩家可以支付贝赎释奴隶并转为族人。

经济资源包括：

- 贝：通用交易与支付媒介（明确的玩法简化）
- 粮食：以 **石** 为游戏单位，主要抽象粟米等人粮
- 草料：马匹与役畜所需
- 牲畜
- 青铜料
- 木骨兵器、弓、青铜戈、青铜矛、战车等实物装备

城邑按季消耗粮食、产生贝和基础物资；秋季收获。军队和民夫从人口中抽走后，会真实降低当地秋收。

## 军队

### 即时征发
- 征发奴隶
- 族兵

这两类只要有人口、简单兵器和基本粮食即可集结。

### 需要训练
- 弓手
- 猎手投矛兵（C级合理复原）
- 青铜戈兵
- 青铜矛兵
- 王族甲士
- 战车乘

正规军必须同时具备人口、装备、贝、粮食和训练时间。

## 民夫与粮道

- 每支军队按兵力和战车数自动计算最低民夫需求。
- 民夫从真实族人 / 奴隶人口征调。
- 民夫不足会限制军队远征。
- 强攻城邑还需要额外民夫进行填壕、梯具和土工作业。
- 粮道会沿己方道路和节点自动寻路。
- 敌军占据渡口、道路节点或补给节点可以切断粮道。
- 粮道分为 **畅通 / 危险 / 中断**。
- 断粮会影响士气并造成逃亡和非战斗损失。
- 玩家无需逐辆操纵粮车。

## 外交与服属

- 关系值和战争状态分离。
- 商与周不会因为阵营不同就开局自动死战。
- 可以赠贝、进行跨境粮食贸易、要求贡纳、宣战和议和。
- 贡纳势力保持自身统治，并非直接染色吞并。
- AI 会根据边界、关系、扩张、威望、实力和战争疲劳动态调整外交。
- 周持续扩张会逐步改变商周力量判断，但不会由脚本强制在固定年份开战。

## 人物

人物不是装饰卡：

- 可以统军；
- 可以担任邑宰 / 主政者；
- 一个人不能同时在远方统军又在城邑主政；
- 统御影响军队表现；
- 治政影响贝收入和秋收。

主剧本使用文丁、季历等与时代相容人物以及必要的合理生成角色。

武丁、妇好等更早的史实人物进入“历代人物档案”，避免跨时代硬塞在同一局中。

## 技艺传播

没有现代式科研点科技树。

技艺可以通过：

- 外来工匠
- 商贸接触
- 征服作坊
- 人口 / 工匠流动
- 战利品与模仿

传播。

已实现效果包括铸造、车作、远程粮运、农业组织、山地行军、畜牧、筑垣等。攻占拥有作坊的聚落或长期贸易都有机会获得对方已有技艺。

## 实时野战

战斗不是“生命值互砍到0”。

每个单位分别计算：

- 人数
- 士气
- 队形
- 疲劳

操作：

- 左键选择己方单位；
- 右键地面移动；
- 右键敌军攻击；
- 可暂停、加速或全军撤退。

地形包含平原、农田、丘陵、森林、泥地等。

战车擅长开阔地机动、侧击、威慑和追击；在森林、泥地、丘陵和攻城战里受到显著限制。

弓手与投矛兵拥有不同射程和地形定位。

军队通常先因士气与组织崩溃而溃逃，之后才在追击中产生更大伤亡，而不是站着打到最后一人。

## 围城

有设防设施的聚落不能直接走进去改颜色。

- 进入围困；
- 逐季消耗城内粮食；
- 粮尽可能屈服；
- 也可选择强攻；
- 强攻时城内会依据实际人口和装备组成守军；
- 实时攻城地图包含壕沟、夯土防线和城门；
- 战车在非城门攻坚方向几乎无法发挥。

## 占卜与祭祀

保持轻量：

- 占卜消耗少量贝，给出不完全可靠的军国提示；
- 祭祀消耗贝和牲畜，提高威望与短期军心；
- 不做繁琐祭品配方和仪式微操。

## 历史可信度标签

- **A**：同时代文字或明确考古直接支持
- **B**：较强学术推定
- **C**：为玩法所作的合理历史复原
- **D**：传奇 / 假设内容

具体人口、粮储、贝价、训练周期属于历史约束下的游戏平衡值，不冒充精确考古统计。

## 自动验收与部署

每次推送到 `main`：

1. JavaScript 语法检查；
2. 地图道路双向和数据引用检查；
3. 每个可玩势力首都 / 人物检查；
4. 浏览器 DOM 实跑：七势力开局、地图渲染、征兵、保存、读取和过季；
5. 自动部署 GitHub Pages。

设计规则见 `docs/design-v0.2.md`。
