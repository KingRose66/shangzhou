# 大邑商：四土（Shangzhou）

一个以商代中后期为背景的大战略 + 战术游戏原型。

当前版本：**v0.1 战略循环 Vertical Slice**

## 当前可玩内容

- 安阳—晋南—晋陕—关中的小范围战略地图，用来验证整张大地图未来要共用的底层规则
- 可选 **大邑商** / **周**
- 人口区分：族人、奴隶；征服可获得奴隶，奴隶可赎买/释为族人
- 通用货币：贝
- 粮食单位：石；军队人吃粟米
- 草料独立计算；战车马匹需要草料
- 奴隶征发兵、族兵可即时征召；青铜正规军必须训练成军
- 民夫与粮道：军队出征需要民夫，粮道中断后只能消耗随军粮草
- 粮食生产与征发劳力挂钩
- 战车、弓兵、青铜戈兵等基础兵种
- 简化战术战斗：士气、队形、疲劳、溃败、追击，而不是“全员战死”
- 人物系统：当前剧本角色 + 前代史实人物档案
- 占卜与祭祀：轻量化，不做繁琐宗教模拟
- 技艺传播：不设现代式科技树；通过工匠、贸易、征服等方式获得技艺
- AI 会征兵、补给并尝试攻击相邻的薄弱节点

## 运行

这是无构建步骤的纯 HTML/CSS/JavaScript 原型。

推荐在仓库目录运行：

```bash
python -m http.server 8000
```

然后浏览器打开：

```
http://localhost:8000
```

直接打开 `index.html` 在多数现代浏览器也能运行。

## 设计原则

每支军队都应该能回答四个问题：

1. 人从哪里来？
2. 武器从哪里来？
3. 粮草从哪里来？
4. 为什么还愿意继续作战？

历史真实性采用分级思路：

- **A**：同时代文字或明确考古证据
- **B**：较强学术推定
- **C**：为玩法所作的合理历史复原
- **D**：传奇/假设内容（史实模式默认关闭）

当前原型中的具体人口、粮储、贝价和训练周期首先服务于验证玩法，并不声称是精确历史统计值。
