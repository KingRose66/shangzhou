# 大邑商：四土（Shangzhou）

**v1.9 · 战略地图视野、地形辨识度与战区聚焦优化**

一款以晚商中后期为背景的浏览器大战略 + 实时战术历史策略游戏。

设计目标不是把《全面战争》简单换成商周皮肤，而是让晚商时代本身产生玩法：人口、族人与奴隶、贝、粮食、草料、青铜装备、民夫、粮道、宗族人物、贡纳网络、情报与战车共同决定一场战争打不打得起、打不打得赢。

## v1.9 战略地图优化

- 默认打开地形晕渲，地图初始缩放增加 0.7 级；地图画布高度由 72vh 扩至 82vh，便于辨认山地、河谷与关隘。
- 地图右上角新增「战区」，快速将镜头移到当前所选城邑并放大周边；新增「放大地图 / 收起地图」切换更大的战略画布。
- 改善地图地貌、路线、河流与地理文字对比度，补充黄河、渭河、汾河、吕梁山等地理标注。
- 保留全部 21 处聚落的原始经纬度、真实位置锚点及避让连接线，不修改行军、补给和野战规则。
- 保留 Windows Edge 鼠标拖动、触控板双指平移、捏合缩放和地形/卫星切换。
- **边界**：目前仍使用现有 NASA/Tom Patterson 自托管地貌影像，并未接入更高精度的数字高程模型。先前 AI 生成的美术插画未配准地理坐标，故没有作为地图底图强行覆盖真实地理位置。

## 主剧本

**西土渐强**

内部时间锚点约设在公元前1115年前后，用于驱动季节和人物年龄。晚商绝对年代存在学术不确定性，因此游戏界面使用“约前××年”，不把这一数字冒充精确史实。

商仍是最强政治中心，周与商保持关系但正在西土成长；晋陕高地、东方、江汉、赣江流域和成都平原存在各自政治集团。所有势力运行在同一张持续战略地图上，不是章节关卡。

## 可玩势力

- 大邑商
- 周
- 晋陕高地方
- 东方诸方
- 江汉诸方
- 吴城文化诸邑
- 成都平原古蜀

各势力胜利目标不同：商偏向恢复贡纳霸权，周需要最终挑战大邑商，其他势力可走区域霸权路线。七个势力均有独立开局军国简报，提示各自的战略约束与首要方向。

## v1.8：图形聚落、点击与野战演练

战略地图使用**有台基、屋顶、土垣/门洞的晚商风格聚落图标**替换旧版13—22像素的实心圆点。它们是便于识别的**游戏美术复原**，不表示考古发现了相同的具体建筑或完整城墙。

- 所有21处战略聚落都有 **52×52像素以上的实际可点击区域**，都城达到60×60像素；不再要求点中针尖大的圆点。
- 地图上的城邑名称也可点击，与图标选择同一地点。密集区域会自动将图标轻微错开，用细线连接原本的真实地理坐标，避免互相挡住。
- 地图上方增加“**城邑速选**”下拉框，可直接定位全部21处聚落，即使聚落名称在当前缩放比例下因拥挤被隐藏也能选中。
- 军旗和人物标记与建筑标记分层显示，避免掩盖城池点击中心；不改变原有 Windows Edge 鼠标拖动、触控板双指平移与捏合缩放。

**实时野战在正式战局内一直存在**：敌对军队在战略路网的同一地点遭遇后，可选择“亲自指挥”进入战场，或者自动结算。两军按道路和城邑/渡口节点接触，不支持在任意像素位置自行画出战线。

为方便直接体验，本版在“军队详情”增加“**亲自指挥野战演练**”：先选中一支我军，选择开阔平原、丘陵、山地或河谷，即可进入和正式战斗相同的实时战术引擎。操练基于该军队的真实编制，并以敌方军队为对手，但所有演练兵力都使用副本，**不减少正式战局士兵、民夫、粮食、草料或外交关系**。

新增 Chromium 浏览器回归测试，逐个检查21座城的有效点击区域、实际点击命中、城名交互及演练不修改战局。

## v1.7：城邑政治、连续行军和更多人物

借鉴《华夏宏图》“多城委任”“内政政策”和“连续军事部署”的玩法目标，但**保留晚商的族邑、邑宰、族人/奴隶、贝、粮石和实物兵器体系**，不套用后世郡县官僚制。

### 施政方针和委任

每个己方城邑可在详情面板设置五类方针（改策消耗60贝，两季内不可频繁改动）：

- **均衡施政**：原有发展方式。
- **劝课农桑**：秋收+18%、贝收入-8%，草料产出增加。
- **鼓励交换**：贝收入+22%、秋收-5%。
- **整饬军备**：木骨兵器与青铜加工+22%、秋收-8%，地方安定恢复较慢。
- **安抚族邑**：地方服从度恢复加速、贝收入-16%。

玩家可给有驻城邑宰的聚落启用“委任治理”。邑宰每隔至少两季，根据粮仓、地方服从、边境形势与作坊条件选择方针，每次自动调策支出25贝。没有任命真实驻城人物的聚落不可委任。AI 势力也使用同一套驻地和任命限制，而非把人物隔空送去主政。

### 军令与补给

- **谨慎推进**：行军粮耗-8%，防御战组织效率+8%，每季沿路线前进一段。
- **常规行军**：标准消耗和战力，每季前进一段。
- **急行推进**：粮耗+25%，在合法道路且粮草/民夫充足时每季最多前进两段；每段损失2点军心，野战效率-8%。
- 选中军队并点击己方或有通行权的目的地后可设定**连续行军路线**。每季自动前进，路线在地图上以蓝色虚线显示，补给线仍用绿色；随时可以取消。
- 自动路线**不会擅自向和平势力宣战、瞬移穿越敌方领土或凭空创造粮草**，道路被敌军占据或粮草/民夫不足时自动暂停/中止。

### 人物扩充

主剧本从 **13人增加至39人**（商10、周9、高地方4、东方4、江汉4、吴城4、古蜀4），新增26人分布在各据点，有实际驻地和明确行政、指挥、工艺能力。新增的族长、史臣、占卜官和工匠都是 **C级虚构复原角色**，不是有甲骨文认证的历史人物。武丁与妇好等更早人物继续保留在档案，不跨时代混入文丁剧本。

v1.2—v1.6 旧存档可迁移；迁移时补入新增人物，不覆盖现有角色、军队和城市进度。

## v1.6：地图交互

- 鼠标左键按住地图拖动平移，也可从城邑标记开始拖动；静止点击仍会选中城邑。
- 触控屏将双指识别为一个连续手势：双指同向移动即平移；张开是放大，收拢是缩小；边移动边张合可同步平移和缩放。
- 手势过程中保留画面即时反馈，松手后再按地理坐标重绘地图，减少触控时的闪烁。
- 独立 Chromium 自动化测试会模拟真实两根触点，覆盖平移、张开、收拢、复合手势及鼠标从城邑拖动。
- v1.5 存档可直接读取。

## v1.4：从抽象节点图升级为真实地貌

战略地图不再使用随意的屏幕百分比坐标和手画的“黄河/太行山”示意曲线。**21个聚落全部改为经纬度坐标**，通过 Web Mercator 将地理位置映射到真实地图上。

- 默认显示 NASA Blue Marble 真实地表影像；可切换 Tom Patterson 公共领域真实地形晕渲。两种模式均内置为本地 WebP 栅格资源，绝不依赖第三方地图瓦片服务器实时加载
- 拖动平移（支持鼠标捕获）、滚轮/按钮缩放、“全图”按 21 座城邑真实位置重新计算地理中心和缩放范围
- 聚落只保留清晰的名称与可识别的势力、都城标识，选中城邑的详细统计放在右侧面板
- 道路是游戏战略抽象叠加层，不伪装成考古确认的晚商道路；选军时补给路线高亮
- 地图显示实际地貌来源署名（NASA Blue Marble / Tom Patterson）。底图展示现代地貌及现代地表，**不宣称卫星照片复原了晚商植被、河道或城墙**
- 地理位置标注 A/B/C 可信等级；“江汉中心邑”一类合成城邑属于区域玩法定位，不是未经证明的精确遗址

**地形不再访问 ArcGIS 在线瓦片服务器**。项目自带 `assets/china-satellite.webp` 与 `assets/china-relief.webp`；首次加载网页所需的仅是站点本身。生成脚本 `scripts/build-terrain.py` 可重复生成资源；GitHub Actions 在部署时自动构建并验证两张图片。受源全球数据分辨率限制，这是一张可缩放的区域战略地理图，并非城市街道级高清卫星图。

## v1.4：人物真实驻地与调动

人物不再只存在于角色卡里：

- 君主、史臣、邑宰、未任命角色位于具体城邑；将领跟随实际军队；拘留者在被拘留地点
- 角色卡明确显示所处位置，城邑详情列出城内人物，地图对驻城人物显示人数标记
- 任命为邑宰或统军者**必须已到该城/军队当前位置**；不能隔着几百里立即获得加成
- 人物可从角色卡调往当前选中的己方城邑，经己方连续道路**每季前进一个节点**；中途断路则停止
- 从军中或行政职务调动人物需要解除原任命；主政者只有在实际驻城时产生经济效果
- 城邑被攻占时，驻城人物可能逃往其他己方城市，也可能被拘留，位置与状态同步
- **旧 v1.2、v1.3 存档可读取**，加载时升级地理坐标与初始人物位置

以上规则尽可能保持操作简单，以保证地图和人物系统确实能玩。

## 人口、经济与地方治理

每个聚落至少区分：

- **族人**
- **奴隶**

征服可以产生俘口 / 奴隶；玩家可以支付贝赎释奴隶并转为族人。

经济资源包括：

- 贝：通用交易与支付媒介（明确的玩法简化）
- 粮食：以 **石** 为游戏单位，主要抽象粟米等人粮
- 草料：马匹与役畜所需
- 牲畜
- 青铜料
- 木骨兵器、弓、青铜戈、青铜矛、战车等实物装备

城邑按季消耗粮食、产生贝和基础物资；秋季收获。军队和民夫从人口中抽走后，会真实降低当地秋收。政权面板现在显示本季预计民食、军粮、秋收、净变化以及断粮/民夫不足警报；属于基于当前条件的预测，战争与突发事件可能使其变化。征募按钮直接显示所需贝、粮、具体兵器、训练季数，并禁用当前无法承担的兵种。四季也会影响行动：夏季河谷行军更费力，冬季军粮、草料和高地远征成本上升。

新征服聚落拥有 **地方服从度**：刚占领时无法立刻贡献完整产能。驻军、邑宰、威望和时间会逐步稳定当地，避免扩张变成无成本滚雪球。

## 军队与训练

### 即时征发
- 征发奴隶
- 族兵

这两类只要有人口、简单兵器和基本粮食即可集结。

### 需要训练
- 弓手
- 猎手投矛兵（C级合理复原）
- 青铜戈兵
- 青铜矛兵
- 王族甲士
- 战车乘

正规军必须同时具备人口、装备、贝、粮食和训练时间。

军队可进行 **分军 / 合军**，因此可以留下偏师守粮道、截渡口或围城，主力继续行动。

## 民夫与粮道

- 每支军队按兵力和战车数自动计算最低民夫需求。
- 民夫从真实族人 / 奴隶人口征调。
- 民夫不足会限制远征。
- 强攻城邑还需要额外民夫进行填壕、梯具和土工作业。
- 军队优先消耗随军粮和驻地粮仓。
- 前线粮仓不足时，会沿己方或有通行权的节点向后寻找自己的有粮聚落。
- 贡纳 / 服属方可提供通道，但不会被自动当成自己的粮仓。
- 敌军占据渡口、道路节点或补给节点可以真正切断粮道。
- 粮道分为 **畅通 / 危险 / 中断**。
- 选中军队后，补给道路会在地图上高亮。
- 断粮会影响士气并造成逃亡和非战斗损失。

玩家无需逐辆操纵粮车，但必须考虑民夫、人手和关键节点。**v1.3** 新增“补足随军民夫”和“从驻地装载军粮草料”：两项操作从实际聚落人口及粮草库存扣减，不会凭空生成物资。行军前会核验粮、草与民夫；对尚未交战的外国聚落会先确认是否宣战，粮不足不会触发无意义的宣战。

## 情报与战争迷雾

外国聚落不会默认显示精确人口、粮仓、兵器和军队数字。

情报分为：

- 未知
- 粗略
- 较详
- 确切

提高情报的方式包括：

- 边境接触
- 贸易
- 服属关系
- 选中邻近军队后派斥候侦察

情报会随时间失效。完全未知区域的外国军队也不会继续“全图透视”显示。

## 外交、贡纳与战争

- 关系值和战争状态分离。
- 商与周不会因为阵营不同就开局自动死战。
- 可以赠贝、跨境粮食贸易、要求贡纳、宣战和议和。
- 贡纳势力保持自身统治，并非直接染色吞并。
- 和平外国军队不会被当成敌军。
- 贡纳 / 服属关系可提供军事通行。
- AI 会根据边界、关系、扩张、威望、实力和战争疲劳动态调整外交。
- AI 战略层会评估首都、人口、作坊、市场、城防和各势力自身方向，沿多节点路线调军，而不是只会攻击相邻城市。
- 对玩家宣战必须经过外交层判断，不允许军队代码在行军时“偷宣战”。
- 周持续扩张会逐步改变商周力量判断，但不会由脚本强制在固定年份开战。

## 人物

人物不是装饰卡：

- 可以统军；
- 可以担任邑宰 / 主政者；
- 一个人不能同时在远方统军又在城邑主政；
- 统御影响军队表现；
- 治政影响贝收入和秋收；
- 人物特质已经进入实际规则。

示例：

- **车战娴熟**：加强所统战车
- **族兵凝聚**：提高族兵组织与士气
- **山地熟习**：改善丘陵、高地作战
- **善治仓廪**：主政时提高经济和秋收
- **青铜工艺**：主政时提高青铜作坊产出

主剧本使用文丁、季历、帝乙、姬昌等与时代相容人物以及必要的合理生成角色。人物会老去、死亡并触发继承；文丁、季历分别设有帝乙、姬昌的继承链。人物与君主的关系会形成忠诚度，忠诚会实际影响统军和主政效率。

武丁、妇好等更早的史实人物进入“历代人物档案”，避免跨时代硬塞在同一局中。

## 技艺传播

没有现代式科研点科技树。

技艺可以通过：

- 外来工匠
- 商贸接触
- 征服作坊
- 人口 / 工匠流动
- 战利品与模仿

传播。

已实现效果包括铸造、车作、远程粮运、农业组织、山地行军、畜牧、筑垣等。攻占拥有作坊的聚落或长期贸易都有机会获得对方已有技艺。

## 军国事件与纪事

v1.2 加入选择型事件系统：

- 商周力量变化与猜忌；
- 文丁—季历的低置信度历史路线；
- 洹水灾歉；
- 军役疲劳；
- 百工与工匠流动；
- 高地、东方、江汉、吴城、古蜀的区域特色事件。

事件会明确标注历史置信度，并提供真正有资源/外交/人物后果的选择。顶部“纪事”按钮会保留完整战役记录，不再只显示最近几十条日志。

## 战前选择

玩家遭遇敌军时，不会被强制直接进入实时战场。

会先看到：

- 双方兵力
- 主将
- 士气
- 粮道
- 兵种构成
- 战场地形

然后选择：

- **亲自指挥**
- **自动交战**
- **撤退避战**

撤退并非无成本，会有少量失散和士气损失。战斗结束后会给出双方战前/战后兵力与损失摘要，损失包含伤亡、溃逃失散与追击，并不等同于“阵亡”。

## 实时野战

战斗不是“生命值互砍到0”。

每个单位分别计算：

- 人数
- 士气
- 队形
- 疲劳
- 朝向

操作：

- 左键选择己方单位
- 右键地面移动
- 右键敌军攻击
- 全军推进 / 全军坚守（默认坚守时会自主迎击接近阵线的敌人）
- 单队操作优先于全军默认命令，支持手动侧击、后撤或指定目标
- 可暂停、加速或全军撤退

地形包含平原、农田、丘陵、森林、泥地等。

战场已经区分 **正面 / 侧击 / 背击**：

- 侧翼攻击会额外破坏队形与士气；
- 背击冲击更强；
- 战车从侧后切入的效果显著高于正面硬撞；
- 青铜矛兵正面迎击高速战车时可以产生反冲代价；
- AI 战车会尝试在开阔地绕击侧后，矛兵会更主动迎战车，戈兵/甲士会优先压迫已经动摇的敌军。

军队通常先因组织和士气崩溃而溃逃，之后才在追击中产生更大伤亡，而不是站着打到最后一人。

## 围城

有设防设施的聚落不能直接走进去改颜色。

- 进入围困；
- 逐季消耗城内粮食；
- 粮尽可能屈服；
- 玩家可以选择强攻；
- 强攻时城内依据实际人口和装备组成守军；
- 实时攻城地图包含壕沟、夯土防线和城门；
- 战车在非城门攻坚方向几乎无法发挥；
- AI 对明显有利的 AI—AI 围城会在若干季度后尝试强攻，不会永远傻等。

## 占卜与祭祀

保持轻量：

- 占卜消耗少量贝，给出不完全可靠的军国提示；
- 祭祀消耗贝和牲畜，提高威望与短期军心；
- 人物特质和王室占卜技艺会轻微影响结果；
- 不做繁琐祭品配方和仪式微操。

## 存档兼容

v1.8 支持读取本地浏览器中的 v1.2—v1.7 存档，读取时增加地理经纬度与人物位置并升级为当前版本。浏览器存档只保存在本机对应浏览器配置中，不会自动跨设备同步。

## 战役结束

胜利或失败后会显示战役摘要，包括历时、控制/稳固聚落、贡纳势力、威望与人口，并允许查看最终地图或直接开始新局。

## 历史可信度标签

- **A**：同时代文字或明确考古直接支持
- **B**：较强学术推定
- **C**：为玩法所作的合理历史复原
- **D**：传奇 / 假设内容

具体人口、粮储、贝价、训练周期属于历史约束下的游戏平衡值，不冒充精确考古统计。

## 自动验收与部署

每次推送到 `main` 都会进行：

1. JavaScript 语法检查；
2. 地图道路双向和数据引用检查；
3. 每个可玩势力首都 / 人物检查；
4. 浏览器 DOM 实跑；
5. 七势力连续 **24 个季度 / 6 年** 的战役 soak test；
6. 战术朝向、侧击、背击和矛兵抗战车逻辑测试；
7. 人物继承、忠诚与世界事件回归测试；
8. 实体粮草装载、民夫补足、未备粮不得宣战、自动防御和旧存档升级回归测试；
9. 用真实无头 Chromium 验证地图图片解码、地形模式切换、拖动平移及“全图”恢复，并输出地图截图；
9. 自动部署 GitHub Pages。
